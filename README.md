## Project Overview

This project examines the relationship between automobile characteristics and vehicle prices using statistical analysis and multiple linear regression in R.

The objective was to identify factors associated with car prices, evaluate their statistical significance, and assess how well a regression model explains price variation.

## Dataset

The analysis uses a dataset containing **205 automobile observations and 25 variables**, including vehicle price, engine size, horsepower, fuel type, curb weight, and fuel efficiency.

The dataset was provided for academic coursework and is not included in this public repository pending confirmation of redistribution permission.

## Tools and Techniques

- **Programming Language:** R
- **Data Preparation:** Data inspection and preprocessing
- **Statistical Analysis:** Hypothesis testing, confidence intervals, and correlation analysis
- **Predictive Modeling:** Multiple linear regression and backward variable selection
- **Model Diagnostics:** Variance Inflation Factor (VIF), residual normality testing, and heteroscedasticity testing
- **Visualization:** Statistical plots and exploratory data analysis

## Key Findings

- The average vehicle price in the dataset was approximately **$13,276.71**.
- The fitted regression model achieved an R-squared value of approximately **0.8763**, explaining about 87.6% of the observed variation in vehicle prices within the sample.
- Regression analysis was used to examine the relationships between vehicle characteristics and prices.
- Diagnostic testing identified concerns regarding residual normality and heteroscedasticity, indicating limitations in the model's assumptions.

## Business Relevance

Understanding the relationships between vehicle characteristics and pricing can support exploratory pricing analysis, inventory evaluation, and more informed business decisions.

The project demonstrates the importance of combining statistical modeling with diagnostic testing before interpreting results.

## Limitations

The analysis was conducted on an academic dataset. The model's explanatory performance does not establish its accuracy on new or unseen vehicles.

Residual diagnostic findings also indicate that some linear regression assumptions were not fully satisfied. Further validation and model refinement would be necessary before using the model for operational price predictions.
